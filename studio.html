首次部署：如何取得 Token 并开启自动发布
  1. 把项目放入一个 GitHub 仓库，分支默认为 main。
  2. 在 GitHub 的 Settings → Developer settings → Personal access tokens → Fine-grained tokens 新建 Token，只授权目标仓库，权限选择 Contents: Read and write。
  3. 在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions。
  4. 填好上方仓库信息并连接。每次替换图片都会生成一次提交，自动部署完成后同一公开网址即可看到新图。
  5. Token 仅用于本页面提交图片，使用后可随时在 GitHub 撤销。
